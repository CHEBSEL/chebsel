Corriger un paiement

CHEBSEL annulera comptablement le paiement d’origine, restaurera les dettes qu’il avait soldées, puis enregistrera le paiement corrigé. L’ancienne opération restera visible dans le journal d’audit.

Restaurer une sauvegarde CHEBSEL

Sélectionnez un fichier JSON généré par le bouton « Sauvegarde complète ». La restauration remplacera les données actuelles de ce portail.

Conseil : avant toute restauration, effectuez d’abord une nouvelle sauvegarde de l’état actuel.
