Le logo fourni est utilisé :

- dans l'en-tête de CHEBSEL ;
- sur la page d'accueil.

INSTALLATION
1. Publiez tout le contenu de ce dossier sur un hébergement HTTPS.
2. Ouvrez l'adresse HTTPS dans Chrome, Edge ou Safari.
3. Android : menu ⋮ > Installer l'application / Ajouter à l'écran d'accueil.
4. Windows : icône d'installation dans Chrome/Edge.
5. iPhone/iPad : Safari > Partager > Ajouter à l'écran d'accueil.

Les données restent locales à l'appareil. Utilisez le bouton 💾 pour les sauvegarder et la fonction de restauration lors d'un changement d'appareil ou de comité.
